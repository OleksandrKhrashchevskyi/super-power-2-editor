Edit the SuperPower 2 database in your browser

SP2 DB Editor opens DATABASE.GDB and the StringTable.*.gst text files, lets you change them, and hands them back ready for the game.

Nothing to install. Your files are copies — the game's originals are never touched.

It runs without a server

The same PHP that powers the hosted editor is compiled to WebAssembly and started inside your tab. A service worker hands every request to it, so the editor behaves exactly as it does on a server — except there is no server. Your database is never uploaded anywhere; it is opened on your own machine.

Work lives in the tab only, so download your files before closing it. For long sessions, or to share one instance with other people, use the hosted editor.

What it does

Everything below works on the file you upload, in the browser, with no game installed.

Browse and edit

All 28 tables with paging, filters and sorting. Edit any value that is not an index or a BLOB.

World map

Thirteen colourings — ownership, language, religion, government, relations, treaties, troops, population. Click a region to edit it, drag to select many and hand them to another country.

Merge countries

Territory, troops, missiles, parties, designs, treaty membership and covert cells all move together, with a preview before anything is written.

Language files

Edit StringTable.*.gst dictionaries. With one open, tables show real names instead of numeric STIDs.

Check and search

Find genuinely broken references, missing capitals and duplicate IDs. Search all tables and the game texts from one field.

Log and undo

Every write is recorded with its previous values and can be put back. A copy of the file is kept before each edit.

The map is built from the database

The game stores no region geometry — only city coordinates and who owns what. The map is rasterised from those, constrained by public-domain Natural Earth outlines. Change an owner and it recolours at once.

Why it is written in PHP

The database is a Firebird 1.5 file from January 2005. That engine exists only for Windows, only 32-bit, so it cannot run on a Linux host at all. The editor therefore reads and writes the file format directly: 4 KB pages, slot tables, RLE records, and the schema taken from the file's own system tables rather than hard-coded.

Everything was cross-checked against a real Firebird 1.5 engine on the same database.

1,382values written back — the engine read exactly what PHP wrote
1 of 16,684values changed by a single-field edit in COUNTRY

Run your own copy

Pure PHP 7.4+. No Firebird, no extensions, no Composer, no build step. Copy the folder onto any host and open it.

git clone https://github.com/OleksandrKhrashchevskyi/super-power-2-editor.git super-power-2
cd super-power-2
php -S 127.0.0.1:8000

Only work/ needs to be writable; the editor creates everything else itself. Details, nginx notes and upload limits are in the README.
